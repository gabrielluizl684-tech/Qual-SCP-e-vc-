Qual SCP você é

Dupla: Daniel Almeida e Gabriel Luiz

| COMO FUNCIONA |

Existe um botão no site que pede uma função, essa função cria variáveis que são o nome, imagem e descrição do SCP.

Essa função também pega um valor aleatório de 0 a 9. Dependendo desse valor, o nome, imagem e descrição mudam para refletir um SCP que escolhi (Exemplo: 0 = SCP-096, 1 = SCP-2521, 2 = SCP-079, etc...).
